## 实现备注（three.js MMDLoader）

- 顶点 morph 用 `mesh.morphTargetDictionary[name]` + `mesh.morphTargetInfluences[i]` 驱动；MMD 表情是加算权重，冲突的嘴型/眉型同时开启会互相拉扯，建议状态机里只激活一组。
- 3 个材质 morph（`照れ`/`目影消`/`目影濃`）MMDLoader 支持有限，需在渲染循环里手动改材质 `color`/`opacity`；`颜赤` 默认 alpha=0，`照れ` 加算 alpha+1 显示腮红。
- bq 符号面片（材质 `biaoq`，贴图 `bq.png`）默认在脑后；对应顶点 morph 把 4–8 个顶点的小面片移到脸旁显示，直接驱动顶点 morph 即可，无需改材质。
- 眨眼建议做成定时器 + `まばたき` 权重缓动；说话时按节奏切 `あいうえおん` 做口型。
