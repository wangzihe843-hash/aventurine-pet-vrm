## 0. TL;DR（给 Lead / 实现同学先看这个）

1. **官方能支撑的**：基础版砂金两套待机动作（有 400×540 官方 GIF + 30fps 实机录屏，可精确到 0.06–0.1s）、
   戏浪站姿与「抬臂 flourish」关键帧（BV1JSev6xEfz 实机试用关卡、720p、角色高约 400px）、
   戏浪官方坐姿（沙滩椅立绘 + 官方 1/7 手办 5 分钟全角度 3D 实拍 + 官方动态壁纸 2D 循环）、
   戏浪全部技能动作 GIF（身体语言/重心参考）。
2. **官方完全没有的**：**戏浪的走路/跑步步态**（PV 是分镜、实机演示全是战斗，秘技 GIF 是冲刺+漩涡特效，不是干净步态）、
   **摸头反应**、**拖拽反应**（星铁游戏内不存在这两个动作）。这三项按任务书用「桌面宠物 + 真人参考 + 设计重构 [C]」补齐。
3. **三条最重要的修正**（对 Wave2 僵硬/诡异/像猴子/半身不遂的直接回应）：
   - 站姿必须有**非对称重心**（contrapposto：支撑腿承重、髋部侧顶 3–5cm、肩线反向倾斜 2–4°）；Wave2 的对称直立是「木偶感」第一来源。
   - 待机必须是**三层叠加**：呼吸（4–5s 循环）+ 重心切换（8–12s）+ 低频小动作（20–40s 随机一次），每层都**不是正弦**，有起-停-回收。
   - 走路必须满足：**0.8–1.0s/步循环（本文取 0.90s）**、脚跟着地→全脚掌→脚尖蹬离的**脚掌滚动**、**手臂与同侧腿反相**、**膝盖任何时刻不得反折**、骨盆上下 2–3cm + 绕垂直轴 ±4–6°。
4. **可验收判据**在 §3 每个动作末尾的单表里，可直接当 QA checklist。
5. **仍缺**：戏浪 4K 待机 GIF（wiki 仍是占位）、戏浪 大世界走路录屏、摸头/拖拽的官方参考——见 §5。

## 2. 官方动作观测事实（只写真看到的 / 量到的）

### 2.1 基础版·待机动作①「摊手展示」（O1，`gifA-armsopen-sheet.png`、`gifA-raise-sheet.png`）[A]

- 全段 11.76s 是官方分镜剪辑（大殿站立 → 面部特写 → 转场粒子 → 梦境地摊手 → 回到大殿站立），**镜头切换点不是动作切点**，beat 表只取同镜头内的连续段。
- **摊手 hold 段：帧 #92–#134 = 5.52s–8.04s（共 2.52s）**：双臂向两侧展开、略低于水平线（手臂与水平线约 -25°～-35°，即往下 25–35°），掌心朝上偏前，肘微屈 10–15°，肩胛放松；身体正面朝镜头，无大重心移动。
- **收臂：帧 #135–#141 = 8.10s–8.46s（0.36s）**：双臂落回体侧，肩先动、手最后到。
- 抬臂段被粒子转场遮住（#72–#87），实操建议 **抬臂 0.8–1.0s [C]**。
- 端姿势（#0–#18，0–1.08s）：正面站立，双臂体侧微屈，双脚与肩同宽。

### 2.3 戏浪·站姿与待机（V1，`frames-xibeach/sheet.png`、`frames-xicrop/sheet.png`、`keyframes/pose-montage.png`）[A]

- t=24.0–25.2：正面站姿。双臂自然垂于体侧、手在髋侧（不贴大腿）、肘微屈 10–15°；双脚与肩同宽、脚尖略外开（约 10–15°）；膝盖不锁死（留 2–3° 微屈）。
- t=25.2–26.0：头微抬、视线上移；头前上方出现金色光球（待机道具/光效，语义未核 [C]）。
- **t=26.0 关键帧 `kf-xi-stand-26s.png`**：右手抬到头部右侧、**掌心向上**（托/接东西的手型），左手垂在体侧；这是「待机小动作」的一帧。
- **t=29.6–32.2（约 2.6s）：抬臂 flourish**（`kf-xi-flourish-30s.png`）：双臂上举/外展、躯干后仰 5–8°、抬头上看，30.8–31.6s 转体侧向单臂高举（欢呼式），31.6s 开始回落。语义（欢呼/招呼/庆祝）未核 [C]，建议作为**低频彩蛋 idle**，不要每次循环都放。
- **t=32.4–37.2：contrapposto 重心转移**：以画面右腿为支撑腿，髋向左（画面右）顶出 3–5cm，肩线反向倾斜约 2–3°；另一腿膝微屈、脚尖外开。
- **t=55.0 关键帧 `kf-xi-stand-55s.png`**：3/4 视角，contrapposto 最清楚——髋顶向画面右（他的左），支撑腿为画面左腿（他的右腿），另一腿膝屈 3–5°，右手在髋侧微屈、左手自然下垂，头略转向他的左侧。
- t=50.0–62.0（室内段）：正面站姿 + 慢环绕镜头；呼吸/微晃周期约 **2.5–3s**（[B]，镜头漂移干扰测量，仅供参考）。

#### W2 细节规则

1. **脚掌滚动**：接触（脚跟着地，踝背屈 5–8°）→ 全脚掌（0.05–0.08s）→ 蹬离（踝跖屈 10–15°）→ 离地。**禁止**整只脚平移/贴地滑行。
2. **膝盖**：摆动腿最大屈 45–55°（Pass 相位），支撑腿最大屈 12–16°（Down 相位）；**任何帧膝角必须 ≥0°**，膝反关节（<0°）严格禁止。
3. **骨盆三面动**：上下 4–5cm、左右 1–2cm、绕垂直轴 ±4–6°；`上半身` 反向旋转（与骨盆差 8–12°）。
4. **手臂相位**：手臂与**同侧腿反相**（左腿前 → 左臂后）；摆幅前后各 12–18°，肘屈 15–25°，手在髋侧摆动，**不要甩到胸上**。
5. **头部**：视线方向稳定，头相对地面转动 ≤±3°（防止点头）。
6. **速度**：步频 2 步/0.9s = 2.22 步/s；若桌宠移动距离很短，可只走 1–2 个循环再减速停（停止时最后一步要「脚跟先落」再并步）。

### 3.3 sit-sitEdge（坐窗口沿 / 桌沿）

**证据**：官方坐姿（O9 立绘 / V8 手办 / V9 动态壁纸）[A] + 桌面宠物坐窗沿行为（P1 官方截图 #4、P2 教程 ≈1:35–1:50、P3 DC≈144–160s）[B]。**戏浪官方坐姿是沙滩椅斜倚，不是窗沿**——本节把「上半身的松弛感」和「窗沿悬腿」结合，标 [C]。

#### SE0 坐姿规格（窗沿）

| 部位 | 目标 |
|---|---|
| `センター` | 落在窗沿上方，臀部后缘距窗沿外沿 4–6cm；y 由窗沿高度决定 |
| `グルーブ`/`腰` | 骨盆后倾 8–12°（坐骨承重），左髋略高 1–2°（非对称） |
| `上半身` | 后仰 3–5°（放松）；绕 Y 转 3–6° 侧向镜头/用户方向 |
| `首`/`頭` | 头抬 2–3°，视线随用户/鼠标 |
| `左足`/`右足` | 髋屈 75–85°；`ひざ` 屈 **85–95°**；`足首` 自然跖屈 **20–30°**（脚尖下垂） |
| 悬垂腿 | 一条腿略前/略直（膝 80°），另一条腿更放松（膝 100°、脚踝跖屈 30°）——**不对称** |
| `左腕`/`右腕` | 一手撑在窗沿上（肘微屈 15–25°），一手放腿上/自然垂在身侧；`手首` 放松 |

#### SE1 进入坐（0.7s）

| t | 可见特征 | 骨骼目标 |
|---|---|---|
| 0.00–0.12s | 低头看落点（**先看再坐**） | `頭` 低 8–12°、`上半身` 前倾 3–5° |
| 0.12–0.35s | 屈膝下蹲，臀部后移 | `センター` y 下降、后移 4–6cm；`ひざ` 屈 55–75°；`足首` 背屈 8–12° |
| 0.35–0.55s | 臀部接触边缘，重心后移 | `腰` 后倾 8–12°；`センター` 再后 2–3cm；`上半身` 前倾补偿 4–6°（保持平衡） |
| 0.55–0.70s | 落定，双腿悬垂，躯干回正 | `上半身` 回到后仰 3–5°；`ひざ` 到 85–95°；`足首` 跖屈 20–30°（脚自然下垂） |

#### SE2 坐定循环（6–10s 一轮，多层叠加）

| 层 | 周期 | 幅度 |
|---|---|---|
| 呼吸 | 4–5s | `上半身` 后仰 ±0.8–1.2°、肩 ±0.8° |
| 悬腿摆动 | 2.5–4s | 小腿前后摆 ±5–8°（`ひざ` 屈曲 ±3–5°），左右腿相位差 0.3–0.5s |
| 手部小动作 | 6–10s | 撑窗沿的手换一次、或手抬到膝盖上 |
| 视线 | 4–8s | 随鼠标/随机扫视；头转 5–10° |
| 身体重心 | 8–15s | 上身左右微倾/换支撑手 |

#### SE3 起身（0.6s）

| t | 可见特征 | 骨骼目标 |
|---|---|---|
| 0.00–0.15s | 上身先前倾（预备） | `上半身` 前倾 6–8° |
| 0.15–0.35s | 臀部离沿、脚落地承重 | `センター` 前移 4–6cm、下降；`ひざ` 屈 60–75°；脚掌落地（全脚掌） |
| 0.35–0.60s | 撑起站直 | 膝盖伸直至 2–5°（不锁死）；回到 S0 站姿（重心在一条腿上） |

#### ✅ sit-sitEdge 可验收判据

| # | 判据 | 红线/数值 |
|---|---|---|
| SE-1 | 臀部与窗沿 | 臀部不穿透窗沿（穿过 <1cm）、不悬空（间隙 <2cm）；坐定后 3s 内位置漂移 <0.5cm |

### 3.4 headpat（摸头反应）

**证据**：**游戏内不存在** [E]。参考：Desktop Mate 官方简介「respond to head pats」[B]、Mate-Engine `FACE_HAIR_STROKE` / `FACE_SMILE` / `FACE_IDLE_1` 动画资产存在（`docs/anim-reference.md`）[A-清单]、P1/P4 的互动视频 [B]。
**设计原则（人设）**：砂金「外松内紧、介意被看到不修边幅」，反应应是**先一愣 → 眯眼接受 → 半秒后恢复营业笑**，而不是立刻傻笑。给「受用但不想承认」的微表情。

#### HP1 beat 表（总 1.6–2.2s；按住时循环）

| t | 可见特征 | 骨骼/表情目标 |
|---|---|---|
| 0.00s | 触发；**头先微转/微低**（0.10s 内出反应） | `首` 向手方向转 ±3–5°、`頭` 低 2–3°；眼（若可）睁大 1 帧 |
| 0.10–0.30s | 眯眼、嘴角上扬；肩放松下沉 | `上半身` 微前倾 1–2°、`肩` 下沉 1–2°；表情切到「眯眼笑/营业笑」（混合时间 0.10–0.15s） |
| 0.30–0.60s | 头跟随手轻晃；头发/呆毛次级运动 | `首` 绕 Z 轻摆 ±2–3°（0.4–0.6s 周期，幅度递减）；发骨/呆毛滞后 0.1s、衰减摆动 |
| 0.60–1.2s | 睁眼瞄一下后继续眯 | 表情「眯眼笑 → 睁眼 0.15s → 眯眼」（可选，增加生动） |
| 按住循环 | 每 1.2–2.0s 一轮微动：头偏/肩动/发摆；**加 ±20% 随机相位** | 同 0.3–0.6s 幅度的一半 |
| 释放 0.0–0.3s | 头回正、睁眼、笑意收回 | `首`/`頭` 回正；表情回「营业笑」 |
| 释放 0.3–0.6s | （可选）轻甩头/整理头发 0.4s | `頭` 轻摆 ±3°（阻尼衰减）；`右腕` 抬到发际线附近（0.4s）再放下——符合「在意仪容」人设 |

#### ✅ headpat 可验收判据

| # | 判据 | 红线/数值 |
|---|---|---|
| HP-1 | 反应延迟 | 触发后 **0.10–0.15s 内开始动**（>0.25s 显得没反应） |
| HP-2 | 方向正确 | 头转向/偏向手的位置（同侧），不得反向；头与手距离 <3cm 时不穿模 |
| HP-3 | 表情混合 | 表情切换 0.10–0.15s crossfade；不得瞬间跳变 |
| HP-4 | 循环无重复感 | 1.2–2.0s 循环 + 随机相位/幅度；连续摸 5s 不出现明显「同一段重复」 |

### 3.5 drag（拖拽）

**证据**：**游戏内不存在** [E]。参考：Desktop Mate / Mate-Engine「Dragging Animation」✅（P1/P2 功能表）[B]、Mate-Engine `PET_DRAGGING.anim` / `HUS_DRAG.anim` / `FACE_DRAG.anim`（v1 清单）[A-清单]。
**设计原则**：**惯性与跟随（overlap）**是「不僵硬」的关键——被拎起时四肢滞后 0.1–0.2s，落下时先触地再吸收。

#### DR1 beat 表

| 阶段 | t | 可见特征 | 骨骼目标 |
|---|---|---|---|
| 被抓/拎起 | 0.00–0.15s | 身体被向上带起，脚离地；头略后仰；手臂先垂后随惯性上抬 | `センター` y 上升；`上半身` 后仰 3–5°；`頭` 后仰 5–8°；`左腕`/`右腕` 向上滞后摆 10–20°（**滞后 0.1s**） |
| 悬空摆动 | 0.15–0.50s | 身体摆动，脚自然下垂、膝微屈 | 腿随惯性摆：`足` 髋屈 10–20°、`ひざ` 屈 15–25°（自然下垂）；`足首` 跖屈 15–25°；摆动周期 0.6–0.9s、幅度随速度衰减 |
| 悬挂移动 | 持续 | 身体朝移动方向倾斜（**朝向自然**），四肢拖后 | `本体` 朝速度方向倾斜 8–15°（相对垂直）；手臂/腿滞后摆；每 0.8–1.2s 微收一次（防僵） |
| 快速甩动 | — | 四肢大幅 lag，头发/衣摆次级 | 四肢滞后 0.1–0.2s、幅度约躯干摆幅的 1.2–1.5 倍；到极限前 0.1s 反向制动（防「橡皮人」） |
| 放下 触地 | 0.00–0.12s | 脚先触地，膝盖吸收 | `ひざ` 屈 20–30° 吸收；`上半身` 前倾 4–6°；`センター` y 下降 1–2cm |

| 站立恢复 | 0.40–0.70s | 回到 S0 站姿；可加一下「整理衣领」小动作（人设） | crossfade 到 idle |
