## 0. 结论速览（TL;DR）

1. **我们手上的 PMX 是"角色本体包"，武器在包外。** 对本地 `assets/model/星穹铁道—砂金·戏浪.pmx` 做了二进制解析（PMX 2.0，32,966 顶点、约 15.5 万三角面、**39 个材质、20 张被引用贴图**）：39 个材质全部是身体/服装/饰品部件（`颜/颜赤/口/白目/舌/齿/目/眉睫/衣1/髪/肌/肌2/印/白襯2/白襯肌/鞋/鞋飾/金飾/珍珠/褲/褲金/褲+/金腰帶/…/目光/目影/鏡片`），**不存在任何武器/水枪材质**；`水枪.png` 在 PMX 内 0 次出现（未被引用）。4 个派生 VRM（`assets/vrm/*.vrm`）材质数与名称完全一致，同样无武器材质 → 不是 VRM 转换丢的，是 PMX 里就没有。
2. **`水枪.png` 可以确认是"那把水枪"的 UV 贴图，不是图标。** 2048×2048、RGB 无 alpha、青蓝+金色配色，图上能看到枪管/握把/扳机护圈/水箱面板/金色羽饰/白色郁金香/小黄鸭/横幅字样的**平面 UV 摊开图**（典型的游戏武器贴图直接导出，非渲染图），说明原作者/上游一定有过一个水枪网格并摊过 UV。
3. **高置信推断：原发布包（或作者工程）里存在独立的水枪模型（多半是独立 PMX，或一个 PMX 内的独立部件），我们这份文件夹缺了它的网格文件，只留了贴图。** 旁证：文件夹里有 9 张**未被 PMX 引用**的残留贴图（`水枪.png / 1.png / h.png / hair5_s.png / Matcap_14.png / Matcap_30.png / mc3.png / toon5.png / 31.bmp`），像是从作者工作目录直接打包的痕迹；而 `Avatar_AventurineW_00_Body_Color_A_LA.png`（5.7 MB，官方内部命名风格）说明作者的贴图来源就是游戏内资源，因此武器也应有对应的游戏内网格来源。
4. **最可能的来源优先级：**
   - **① Lead 正在查的 138 个 .max 全场景 FBX —— 优先级最高。** 中文 CG/动作圈的崩铁角色 `.max` 包**习惯把武器作为独立物体塞在角色头部位置且不绑骨骼**（有直接证据，见 §2.1 CGJOY 砂金 max 帖原文"无武器道具绑定（武器等东西在脑袋里面，大家可以自己拿出来绑一下）"）。只要 138 个场景里有一个含武器物体，导出 FBX 就是成本最低、画质最高、授权上"同一作者/同一来源"的解法。
   - **② 找回原始 MMD 发布包里的武器 PMX。** 原发布页未能定位（模之屋 aplaybox 为 SPA 且需登录，搜索站内未命中；BowlRoll 需登录；未在公开搜索中找到带文件清单的原始发布页）→ **无法证实原包是否真的含水枪 pmx**，只能按贴图存在性推断"应该有"。若用户能翻出当初下载的压缩包/网盘链接，是最快的核实手段（本地文件夹可能只是解压时漏拷）。
   - **③ 游戏内资源提取（AssetStudio 系 fork / 3Dmigoto dump）** —— 工具链存在（`Sycamore0/SRStudio`、`Escartem/AssetStudio`、`Melioli/HoYoStudio`、`blender-3dmigoto-importer`），但**版本门槛是硬伤**：现有公开 fork 的 README 标称支持到 StarRail 2.7+（`Escartem/AssetStudio`），对 4.5 的新 bundle 加密/hash 大概率不适用；且流程重、需要本机安装游戏客户端、合规风险最高。**本文只记录工具名与流程，不实操、不下载。**
   - **④ 社区同款模型** —— 有外形同款但**都不是可用的 MMD 网格**：Cults3D 付费 3D 打印模型「Aventurine • Waveflair Water Gun」、Roblox UGC 饰品「Aventurine Waveflair - Watergun (Back)」、MakerWorld 免费 3D 打印「砂金·戏浪鸭子挂件」（只有鸭子挂件、非枪）。可作**造型参考**，不能直接转网格，且这些站点的授权不允许拆网格复用。
   - **⑤ 兜底：对照贴图手工重建低模。** 因为贴图已经是**摊好 UV 的成品图**，可以 1:1 反推低模，这是**最可控、无额外来源风险**的路径。成本估计：**首版 6–12 人时**（含鸭子/郁金香/羽饰/枪体/扳机/握把），**熟手 3–6 人时**；若只做桌面宠物远景可用简化版 **2–4 人时**。
5. **版权红线：** 水枪网格（无论来自 .max 提取、游戏内提取还是原 MMD 包）都是 **miHoYo 版权资产**；本机私有使用 OK，**不得上传/分发/二次配布/商用**，也不要放到公开仓库或云端（当前仓库无 remote 也应保持）。原 PMX 作者"流云景"的规则同样覆盖其编辑部分。社区站点（Cults3D/RenderHub/CGJOY）上的模型多为**付费授权且禁止再分发**，即使外形一致也不等于拿到网格授权。

## 2. 调研发现

### 2.1 游戏资源组织方式 & 中文 CG 圈惯例（武器在不在"角色包"里）

- **HSR 是 Unity 游戏，资源以 bundle/AssetFile 组织，角色（avatar）、武器、特效是同一角色资源族里的不同对象**；社区提取（AssetStudio 类工具）时通常能在一个角色 AssetFile 里同时看到身体 Mesh、武器 Mesh、以及各自的 Material/Texture（武器与角色是**不同 Mesh/材质对象**，但常被打包在同一个角色 prefab 集里）。**置信度：中**（来自工具链与社区提取惯例的推断，本次未找到一份明确写出"武器 asset 路径"的公开文档；受时间限制未做提取实操验证）。
- **直接证据（高置信）**：CGJOY 2025-12-19 发布的《【崩坏：星穹铁道】砂金》`.max` 帖子（13.82 MB、2018 版 Max、5 CG 券）原文写明：
  > "无表情绑定 / **无武器道具绑定（武器等东西在脑袋里面，大家可以自己拿出来绑一下）**"
  → 即**武器网格在提取的模型文件里真实存在，只是被放在头部位置、没有绑定**。这说明：**如果 Lead 手里的 138 个 .max 全场景来自同一类分享包，水枪网格很可能就藏在某一个场景的某个物体里**（通常命名形如 `weapon`/`wp_`/`枪`/`水枪`/`prop`，或直接是无名 Mesh/Editable Mesh 对象，位置在头部附近）。
- 该帖也印证：中文 CG 圈的崩铁 `.max` 资源本身就是**游戏提取+重绑定**的产物，属灰色地带；作者/卖家加"禁止二次配布"声明并不能改变 miHoYo 版权归属。

### 2.5 兜底：用贴图 + 基础几何反推低模（成本估计）

**可行性：高。** 因为 `水枪.png` 是**已摊好 UV 的 2K 贴图**，不是渲染图，可以直接当作"UV 布局图 + 颜色参考"来反推网格：

1. 在 Blender 里把 `水枪.png` 贴在平面上当参考底图，用 UV 岛边界判断部件划分（枪体/枪管/握把/扳机/装饰/鸭子/郁金香/羽饰）。
2. 按 UV 岛逐个建低模（简模/挤出/倒角），或先用 Cube+细分快速卡形再 retopo。
3. 把 UV 岛对齐到贴图区域（Blender "UV → 从视图投影/对齐到贴图岛"），必要时手工微调 UV。
4. 输出 glTF/VRM 挂点给运行时（另一端由队友负责）。
5. 若需还原描边/toon：材质用 MToon 或自定义 outline pass，参考模型已有 `toon3/4.png` 的卡通渐变；阴影一侧可用贴图自带的预烘焙明暗，减少重建工作量。

**成本估计（人时，单人、含 UV 对齐与基本材质）：**

| 精度档 | 内容 | 估计工时 |
|---|---|---|
| 远景/桌面宠物简化版 | 枪体+枪管+握把+鸭子 4 个部件，约 1–3k tris | **2–4 h** |
| 标准版（推荐） | 全部主要部件 + 扳机/水箱/羽饰/郁金香 + UV 对齐 + MToon 材质 | **6–12 h（首版）；熟手 3–6 h** |
| 高还原版 | 加细节件、硬表面倒角、描边与高光对位、挂点/骨骼 | 12–20 h |

（外包报价不在本文虚构范围；如需外包请自行询价，且注意外包方拿到贴图=二次流转风险。）

